# Projeto 01 — Testes de API

## Sobre o projeto

Coleção de testes de API desenvolvida com Postman, utilizando a API pública JSONPlaceholder.

## Objetivo

Praticar testes de APIs REST, validação de requisições HTTP, códigos de status, respostas JSON e scripts automatizados de teste.

## Cenários de teste

- GET — Listar usuários
- GET — Consultar usuário inexistente
- POST — Criar usuário
- PATCH — Atualizar nome do usuário
- PUT — Substituir dados do usuário
- DELETE — Excluir usuário

## Ferramentas

- Postman
- API REST
- HTTP
- JSON
- JavaScript

## Observação

O JSONPlaceholder é uma API de simulação. As operações de criação, atualização e exclusão não persistem alterações reais nos dados.

## Coleção Postman

O arquivo JSON exportado do Postman será disponibilizado nesta pasta para consulta e execução dos testes.
